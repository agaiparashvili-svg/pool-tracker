# 📦 საწყობი — მარაგების კონტროლი (PWA)

ცალკე, ტელეფონში დასაინსტალირებადი აპლიკაცია საწყობისთვის:
**შეკვეთები** (რა შევუკვეთეთ), **ჩამოსვლა** (რა ჩამოვიდა) და **მარაგების კონტროლი**.

აპი იყენებს იმავე Firebase პროექტს და იმავე ანგარიშებს (`pool_users`),
რომელსაც „აუზების რეპორტის" აპი — ცალკე რეგისტრაცია არ სჭირდება.

## გვერდები
- **📊 მთავარი** — მიმოხილვა: სულ პროდუქტი, დაბალი მარაგი, მოლოდინში შეკვეთები, ბოლო ჩამოსვლები.
- **📦 მარაგი** — პროდუქტების სია მიმდინარე ნაშთით. ＋ ღილაკით ახალი პროდუქტი.
  ყოველ პროდუქტზე: ➕ ჩამოსვლა, ➖ გაცემა, ✏️ რედაქტ., 🗑 წაშლა (ადმინი).
  დაბალი / ამოწურული მარაგი ფერით გამოიყოფა.
- **🛒 შეკვეთები** — ＋ ღილაკით ახალი შეკვეთა. „✅ ჩამოვიდა" ღილაკი ნაშთს ავტომატურად ზრდის.
- **📥 ჩამოსვლა** — რა და როდის ჩამოვიდა (შეკვეთიდან ან პირდაპირი მიღებით), თარიღით ფილტრით.

## ⚠️ აუცილებელი ნაბიჯი — Firestore წესები
რომ მონაცემები შეინახოს, Firebase Console → Firestore Database → **Rules**-ში
დაამატეთ ეს ბლოკები (არსებულ `pool_users` / `pool_reports` წესების გვერდით):

```
// საწყობის კოლექციები — მხოლოდ დადასტურებული მომხმარებლები
function whOk() {
  return request.auth != null &&
    get(/databases/$(database)/documents/pool_users/$(request.auth.uid)).data.role in ['admin','operator'];
}
match /wh_products/{id} { allow read, write: if whOk(); }
match /wh_orders/{id}   { allow read, write: if whOk(); }
match /wh_moves/{id}    { allow read, write: if whOk(); }
```

თუ თქვენი Firestore უკვე ღია წესებზეა (`allow read, write: if request.auth != null;`),
დამატებითი არაფერი სჭირდება.

## ტელეფონში ინსტალაცია
აპი უნდა გაიხსნას **HTTPS**-ით (მაგ. GitHub Pages, Firebase Hosting ან ნებისმიერი ჰოსტინგი).
1. გახსენით აპის მისამართი `…/warehouse/` ბრაუზერში.
2. **Android (Chrome):** ჩამოვა ბანერი „დააინსტალირეთ აპლიკაცია", ან მენიუ → „Add to Home screen".
3. **iPhone (Safari):** Share → „Add to Home Screen".
ინსტალაციის შემდეგ ცალკე აიქონი გაჩნდება — გაიხსნება სრულეკრანიან რეჟიმში, აპის მსგავსად.

## ფაილები
- `index.html` — მთლიანი აპლიკაცია (UI + ლოგიკა)
- `manifest.webmanifest` — PWA კონფიგი
- `sw.js` — service worker (ოფლაინ გაშვებისთვის)
- `icons/` — აიქონები
- `gen_icons.py` — აიქონების გენერატორი (stdlib-ით)
